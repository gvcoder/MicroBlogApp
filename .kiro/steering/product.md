# Product Overview

## Personal Notes Platform

A web-based application that allows users to register, login, and manage text-based notes. Users can create, read, update, and delete notes, search notes by keywords, and filter notes by tags. The platform provides a simple, intuitive interface similar to Google Keep for efficient note-taking and organization.

## Core Features

- **User Authentication**: Registration, login, logout with secure session management
- **Note Management**: Full CRUD operations for text-based notes
- **Search & Filter**: Keyword search and tag-based filtering
- **Data Persistence**: MySQL database with proper data integrity
- **API Security**: Session-based authentication and authorization

## Target Users

- Individuals who need a simple note-taking solution
- Users who want to organize notes with tags
- People who need quick access to their notes across devices

## Key Requirements

1. Users must be able to register with email and password
2. Users must be able to create, read, update, and delete notes
3. Notes must support titles, content, and optional tags
4. Users must be able to search notes by keywords
5. Users must be able to filter notes by tags
6. All data must be persisted securely
7. API must be secure with proper authentication

## Success Metrics

- User registration and login success rate > 95%
- Note creation/retrieval response time < 1 second
- Search/filter response time < 500ms
- System uptime > 99.5%
- Data integrity maintained across all operations
